¿Cómo consigo mi clave?
  1. En github.com tocá tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: Estudio web. Vencimiento: el más largo que te deje.
  3. Repository access: Only select repositories → juanguzmanph.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copiala (empieza con github_pat_) y pegala acá.

La clave queda guardada solo en este dispositivo. Sin ella nadie puede cambiar nada.
