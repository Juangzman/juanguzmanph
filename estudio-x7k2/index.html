Estudio

Tu espacio privado para elegir y ordenar las fotos de la web.

Primera vez: entrá con tu clave de GitHub y después creá tu usuario en Accesos. Desde ahí en adelante, entrás con usuario y contraseña.

¿Cómo consigo la clave de GitHub?
  1. En github.com tocá tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: Estudio web. Vencimiento: el más largo que te deje.
  3. Repository access: Only select repositories → el repositorio de la web.
  4. Permissions → Add permissions → Contents → Read and write.
  5. Generate token, copiala (empieza con github_pat_) y pegala acá.
